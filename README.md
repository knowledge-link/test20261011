# 大石の打合せの持ち物

打合せ前の持ち物を確認できる、シンプルなチェックリストです。HTML・CSS・JavaScriptを1つの `index.html` にまとめているため、インストールやビルドは不要です。

## 機能

- 持ち物の追加・削除
- チェック済みの項目に取り消し線を表示
- 準備の進み具合を件数とプログレスバーで表示
- リセットボタンですべてのチェックを解除（項目は残ります）
- ブラウザへの自動保存
- スマートフォンに対応

## 使い方

1. 準備できた持ち物にチェックを入れます。もう一度押すとチェックを外せます。
2. 下の入力欄に持ち物を入力し、「＋ 追加」またはEnterキーで追加します。
3. 項目の右にあるゴミ箱ボタンで削除します。
4. 次の打合せの前に「チェックをリセット」を押すと、すべてのチェックを外せます。

最初は「ノートパソコン」「充電器・ケーブル」「名刺」「打ち合わせ資料」「筆記用具・ノート」「スマートフォン」が登録されています。

`index.html` をダウンロードし、ブラウザで開いてください。

## GitHub Pagesで公開する

1. GitHubで公開用のリポジトリを作成します。GitHub Freeを使う場合は、Publicのリポジトリを選びます。
2. リポジトリの一番上の階層に `index.html` と `README.md` をアップロードしてコミットします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** でファイルを置いたブランチ（通常は `main`）と **/ (root)** を選び、**Save** を押します。
6. デプロイが完了したら、Pagesの設定画面に表示されるURLからページを開きます。

公開後に変更するときは、同じリポジトリの `index.html` を更新してコミットしてください。

GitHub公式ガイド：<https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>

## 保存について

持ち物とチェック状態は、利用しているブラウザの `localStorage` に保存されます。ページを再読み込みしても状態を引き継げます。

- 別の端末やブラウザとの同期はありません。
- ブラウザのサイトデータを削除すると、保存した内容も消えます。
- プライベートブラウズや保存を制限した環境では、保存できない場合があります。
- 保存先はページの配信元ごとに分かれます。手元で開いたHTMLや別のURLのデータは、GitHub Pagesへ自動移行されません。
- このページには、持ち物の内容をサーバーへ送信する処理はありません。
